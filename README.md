# Customer Segmentation Analysis using K-Means Clustering
Customer Segmentation Analysis using K-Means Clustering and Python


## Project Overview
This project analyzes customer behavior using K-Means Clustering to identify distinct customer segments based on annual income and spending patterns. The goal is to help businesses understand customer groups and develop targeted marketing strategies.

## Objectives
- Analyze customer demographics and spending behavior
- Perform customer segmentation using K-Means Clustering
- Generate actionable business insights
- Recommend targeted marketing strategies

## Dataset Features
- CustomerID
- Gender
- Age
- Annual Income (k$)
- Spending Score (1-100)

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn
- Google Colab

## Methodology
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Selection
4. Feature Scaling
5. Elbow Method
6. K-Means Clustering
7. Cluster Profiling
8. Business Insights & Recommendations

## Key Findings

Five customer segments were identified:

### Premium Customers
- High Income
- High Spending
- Most valuable customer segment

### Careful Customers
- High Income
- Low Spending
- Opportunity for personalized marketing

### Impulsive Customers
- Low Income
- High Spending
- Respond well to promotions

### Budget Customers
- Low Income
- Low Spending
- Price-sensitive segment

### Average Customers
- Moderate Income
- Moderate Spending
- Largest mainstream customer group

## Business Impact
Customer segmentation enables businesses to:

- Improve marketing effectiveness
- Increase customer retention
- Personalize customer experiences
- Optimize resource allocation
- Improve revenue generation


## Results

The K-Means Clustering model successfully identified five distinct customer segments:

- Premium Customers
- Careful Customers
- Impulsive Customers
- Budget Customers
- Average Customers

These segments provide valuable insights for targeted marketing and customer retention strategies.

## Project Outcome
This project demonstrates the practical application of machine learning and data analytics techniques to solve real-world business problems through customer segmentation.
